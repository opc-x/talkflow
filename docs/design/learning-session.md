---

## 核心逻辑

Callan Method 的原子单元：

```
词汇引入 → 被提问 → 回答 → 下一个
```

对应数据库结构：

```
lexical_block（词汇组）
  └── qa_block × N（紧跟的问答，直到下一个 lexical_block）
```

用户在 App 里经历的是这个序列，不是随机的，是顺序走完一课。

## 待决定的设计问题

以下三个问题决定了整个体验感，边做边定：

### Q1：翻页方式
- [ ] 用户手动点「下一个」（控制感强，Callan 原版节奏）
- [ ] 答完反馈后自动跳下一个（流畅，像 Duolingo）
- [ ] 键盘快捷键 Space = 看答案，← → = 前后翻页

### Q2：一个 Session 的范围
- [ ] 一整课（一个 lesson，约 20-40 个 block）
- [ ] 一页（book_page，约 5-10 个 block，更短更快完成）
- [ ] 自定义题数（10 / 20 / 30）

### Q3：视觉风格
- [ ] 极简白底，大字，留白多（类 Kindle）
- [ ] 暗色模式为主
- [ ] 随便，上去再调

## 数据流（实现参考）

```
用户打开 Session
  → 读 user_progress（上次到哪一课哪一页）
  → 拉对应 lesson 的所有 content_blocks（按顺序）
  → 按 lexical_block → qa_block 分组展示
  → 用户反馈（记住/没记住）→ 写 review_schedule（SM2）
  → 进度 +1 → 写 user_progress
```

**相关表：**
- `content_blocks` — 内容本体
- `user_progress` — 当前学到哪
- `review_schedule` — SM2 复习队列（已预留）
- `session_records` — 本次 session 记录
