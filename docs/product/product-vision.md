# TalkFlow 产品思路

## 核心 Loop（不可妥协的骨架）

情景图片 → 动画引导 → AI 实时对话 → 可见进度 → 激励回来 → 循环

## 差异化组合（市场上没有完整实现的）

| 要素 | 作用 |
|------|------|
| 看图说话（场景图） | 降低开口焦虑，有具体锚点 |
| 动画模拟引导 | 替代真人教师示范 |
| AI 实时陪练 | 随时随地，不怕被嫌烦 |
| 阶梯式游戏化奖励 | 解决坚持不下去的问题 |
| 承诺退款保证 | 打破"花钱没效果"的信任壁垒 |
| 价格 | 打破线下机构高收费，直接降维打击 |

## 竞品扫描结论

- **Duolingo** — 没实时对话
- **Speak** — 没情景引导，无游戏化，且贵
- **ELSA** — 只纠发音
- **线下 Callan** — 贵且时间固定

五要素组合市场是空白。
