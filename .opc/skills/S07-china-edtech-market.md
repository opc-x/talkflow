# S07 — 中国英语教育市场

## 职责

理解 TalkFlow 所在市场环境，支持定价、营销、融资叙事。

## 市场规模

- 中国英语学习市场：~3000亿人民币/年
- 成人英语口语细分：持续增长（职场需求驱动）
- 在线化率：疫情后加速，预计持续

## 竞品地图

```
高价 ←──────────────→ 低价
 │                     │
Cambly (真人外教)    多邻国(免费)
italki ($15+/小时)   扇贝/百词斩
 │                     │
 └──── TalkFlow ────────┘
       (AI口语, 中低价)
```

| 竞品 | 优势 | 劣势 |
|---|---|---|
| Cambly | 真人沉浸感 | 贵(¥100+/小时)、难坚持 |
| 多邻国 | 免费、习惯养成 | 口语弱、碎片化 |
| italki | 真人外教灵活 | 门槛高、价格不稳定 |
| **TalkFlow** | AI+结构化+SRS | 知名度低 |

## 监管风险

- 双减政策：针对K12，成人英语暂不受限
- 录音数据合规：用户语音数据本地处理优先
- AI内容审核：教育类需注意

## 出海机会

- 越南/印度/东南亚英语学习需求大
- 产品架构支持多语言（已有locale结构）
