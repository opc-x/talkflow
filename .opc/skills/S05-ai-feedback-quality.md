# S05 — AI反馈质量

## 职责

评估和提升 TalkFlow AI 反馈的质量，确保反馈有效促进口语进步。

## 好反馈 vs 坏反馈

| 坏反馈 | 好反馈 |
|---|---|
| "你的发音不准确" | "cat里的'a'音偏长，试试短促的/æ/：cat, hat, bat" |
| "流利度需要提高" | "第二句前停顿了3秒，可以用'Well...'或'Let me think...'过渡" |
| 列了5个问题 | 只说1-2个最重要的 |
| 纯文字 | 包含示范句让用户模仿 |

## 质量指标

```
可行性：用户能立刻知道怎么改 (0-5)
具体性：有例子/对比/示范句 (0-5)
鼓励性：正向情绪，不打击信心 (0-5)
精准性：针对这个用户这句话 (0-5)
```

## Prompt 优化方向

- System: 扮演有耐心的英语外教，学生是中国成年人
- 限制：反馈控制在100字以内，改进点不超过2条
- 格式：先肯定 → 改进点 → 示范句
- 语言：默认中文解释 + 英文示范句
