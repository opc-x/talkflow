# S06 — EdTech留存指标

## 职责

定义和追踪 TalkFlow 关键留存指标，指导产品迭代优先级。

## 核心指标体系

```
获取 → 激活 → 留存 → 变现 → 推荐
  ↓       ↓       ↓       ↓       ↓
注册   完成首课  Day7回来  付费   分享邀请
```

## 关键数字目标（第1圈）

| 指标 | 定义 | 目标 |
|---|---|---|
| 激活率 | 注册→完成onboarding | >60% |
| D1留存 | 第2天回来练习 | >40% |
| D7留存 | 第8天回来练习 | >20% |
| D30留存 | 第31天仍活跃 | >10% |
| 课程完成率 | 开始→完成 | >70% |
| 付费转化 | 免费→付费 | >5% |

## EdTech留存规律

- 免费试用 ≤ 3课（太少没感觉，太多不付费）
- 进度条/streak 是留存最强杠杆
- 第一个"口语进步时刻"必须在48小时内发生
- 每日学习提醒：晚8-9点打开率最高

## 数据来源

- `session_records` → 活跃天数/连续学习
- `qa_responses` → 准确率趋势（进步感）
- `review_schedule` → SRS参与率
