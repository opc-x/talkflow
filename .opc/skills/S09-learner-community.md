# S09 — 学习者社区

## 职责

TalkFlow 社区冷启动策略和病毒传播机制设计。

## 冷启动路径

```
第0步：10个种子用户（创始人亲自招募）
  ↓
第1步：建微信群（私域），每天晒打卡
  ↓
第2步：用户口语进步截图 → 朋友圈扩散
  ↓
第3步：邀请好友得额外月份（裂变）
  ↓
第4步：大V/英语博主合作推广
```

## 种子用户来源

- 创始人微信好友（英语学习需求筛选）
- 考研/托福备考群
- 职场英语交流群
- 小红书"英语焦虑"话题下回复

## 社区激励机制

| 行为 | 激励 |
|---|---|
| 每日打卡 | 连续奖励 badge |
| 分享进步 | 解锁隐藏课程 |
| 邀请好友 | 双方得30天专业版 |
| 完成一册 | 生成精美证书（可晒朋友圈）|

## 关键指标

- 种子用户NPS > 50（才值得扩大推广）
- 口碑核心：第一个"哇我说出来了"的时刻
- 流失拉回：7天未登录 → 个性化唤醒推送
