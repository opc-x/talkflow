# S03 — 中国英语学习者研究

## 职责

理解目标用户心理、行为模式、障碍点，指导产品和内容决策。

## 核心用户画像

```
年龄：22-35岁
职业：大学生/白领/考研党
痛点：
  1. 哑巴英语（会读写，不敢说）
  2. 怕出错，说前过度思考
  3. 没有真实开口环境
  4. 传统课程枯燥，坚持不下去
动机：
  - 考试（四六级/考研/托福）
  - 职场晋升（外企/出海）
  - 个人成就感
```

## 学习行为规律

| 行为 | 数据参考 |
|---|---|
| 最佳练习时长 | 15-20分钟/天 |
| 坚持率崩溃点 | 第3-7天（新鲜感消退） |
| 最有效激励 | 可见的进步（streak + 等级） |
| 放弃原因 | 看不到进步、太难、太无聊 |

## 产品启示

- 每课控制在15分钟内
- Day3/Day7 主动推送（防流失节点）
- 进步可视化比功能更重要
- 第一开口不能太难（A1先让用户成功）
